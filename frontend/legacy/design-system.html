Project Dashboard 設計語言

專案管理儀表板（甘特圖 · 任務看板 · Issue 看板 · 成員面板）的一致設計語言。所有數值實測自互動實作 Project Dashboard.dc.html；實作即為行為的最終依據。

核心原則

膠囊即原子所有可編輯屬性（狀態、日期、工期、等級、成員）都是 20px 圓角膠囊（Node）+ ▼，點擊開浮層；不用原生 select / date input。
數字等寬日期、計數、工期一律 IBM Plex Mono，日期零補位 2026/09/18、09/24 → 10/06，字元數固定，位數變化不會推移相鄰控制項。
版面不跳動hover 顯示的控制項用 max-width / opacity 淡入；數字欄位固定寬；行高取整數像素；sticky 元素加 translateZ(0)。
無裝飾無漸層、無圖片、無材質、無 emoji、無圖示字型。卡片無陰影，陰影只給浮層。
對比 ≥ 4.5:1正文最淡到 --text-muted #64748b；#94a3b8 只用於圖示、placeholder、▼。

色彩

底色三階 + 邊框三階 + 文字五階；主色藍只用於選取、焦點、進度與排序。狀態色每組三值（文字／長條／圓點）。

RULES

行高標題 1.22；卡片名稱固定 20px 兩行截斷（min-height 38px）；內文 1.4–1.65。所有行高取整數像素。
日期格式完整 yyyy/mm/dd（2026/09/18）；卡片短式去年份 mm/dd → mm/dd，箭頭左右各一空白；完整日期放在 title tooltip。
數字欄寬工期數字右對齊、固定寬（兩位數：20px），日期短式固定 96px（實作中為 88px，本頁字型渲染略寬），確保 ▲▼ 不位移。
截斷名稱不可壓縮（flex 0 0 auto）時以 ellipsis 截斷並給 title；日期永遠完整顯示。

文案規範

語言繁體中文為主；技術名詞保留英文（Issue、Gantt、BIOS、Due Date、Critical / Major / Minor / Limitation）。表單標籤中英並列：「建立者 Initiator」。
語氣工具型、簡短、陳述句；不用「您」「請」開頭。按鈕是動作名：「＋ 新增任務」「今天」「送出」「清除篩選」「刪除 Issue」。
空狀態直述：「此篩選條件下沒有留言」「尚無留言成員」。
提示放在 title tooltip，不佔版面：「雙擊可修改名稱」「實際完成日期（狀態改為已完成時自動填入）」。
數字一律 mono；日期零補位；區間 2026/09/24 → 2026/10/06 · 13d；計數「顯示 30 / 共 30 個任務」。
確認刪除一律二次確認，標題問句 17.2px：「確定要刪除此任務？」，主按鈕紅色。
禁止emoji、驚嘆號、行銷語、字母代碼與文字並列（A · Critical）。
